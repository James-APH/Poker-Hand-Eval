# Poker-Hand-Eval

Made using the Elixir Programming Language.

## Project Overview

After being dealt a random Poker Hand, it can tell you what type of hand you
have. I sought to maintain pure functional programming standards, and all of
this code does not mutate any data.

## Reflection

This project got me deeper into functional programming; I learned about how
I can use Elixir Structs, Modules, Types, atoms, and Pattern Matching!! I'm
not too fond of how dynamic Elixir is; I usually prefer languages that have strong
typing, but from the blog posts on their site it seems the developers behind the
language might be moving toward that.

Pattern matching is something I have learned about using languages like Rust,
Kotlin, but Rust is really complicated so that was never my main focus, and
Kotlin only goes so far. I really love the Match statement, and have become
quite fond of destructuring.

I absolutely love how documentation is handled; I think all programming
languages should aspire to have something like @spec, as well as the
documentation generator `ex_doc`. This was also the first language where I
truly experienced the thrill of the pipe operator; I am really loving the
concepts used in functional programming.
